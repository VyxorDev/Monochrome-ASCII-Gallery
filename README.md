**Just characters. No colors. No images. Maximum detail.**

## Mobile-friendly previews

For narrow screens, start with **[the mobile gallery](art/mobile/)**. Each mobile piece is 44 characters wide or less; use a monospaced font and disable word-wrap where possible.

## How to view it correctly

1. Open any `.txt` file, or click **Raw** on GitHub to select/copy all text.
2. Use a **monospaced font** (Consolas, Cascadia Mono, Menlo, or any fixed-width font).
3. Disable soft-wrapping in your viewer. On mobile, start with the `art/mobile/` folder.
4. Keep spaces and line breaks intact when sharing; proportional fonts distort the picture.

## Gallery rules

- **Monochrome:** printable 7-bit ASCII only, no Unicode block characters or emoji.
- **No colors:** no ANSI escape codes, RGB, or terminal styling.
- **Detailed:** prefer intentional compositions and crisp texturing over low-resolution doodles.
- **Original and permission-safe:** only submit art you made or have permission to publish.
- **Plain-text first:** one finished artwork per `.txt` file.
